# Power-BI-Sales-Analysis
Interactive sales analysis dashboard built using Power BI, featuring sales and profit analysis, slicers, geographic visualization, hierarchies and drill-through.
# Power BI Sales Analysis Dashboard

## Project Overview

This project focuses on analyzing sales performance using Power BI. The dashboard presents sales and profit across different product sub-categories and provides interactive features to explore the data.

## Objectives

- Analyze sales performance across product sub-categories.
- Compare yearly sales from 2014 to 2017.
- Review sales, profit and quantity metrics.
- Explore sales data across different regions.
- Use filters and slicers to make the analysis interactive.
- Apply hierarchies and drill-through to explore detailed information.

## Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization
- Interactive Reports and Dashboards

## Dashboard Features

### 1. Sales Summary
A table showing sales, profit and quantity for different product sub-categories, along with a bar chart comparing sales performance.

### 2. Filters and Slicers
Interactive category, region and order date filters allow users to explore selected portions of the dataset.

### 3. Geographic Analysis
A map visual displays geographic sales information to support regional exploration.

### 4. Hierarchies
Hierarchies allow users to navigate through different levels of the data for more detailed analysis.

### 5. Drill-Through
Drill-through functionality enables users to move from summarized information to a more detailed view of selected data.

### 6. Yearly Sales Comparison
A matrix compares sales across 2014, 2015, 2016 and 2017, with totals by sub-category.

## Key Skills Demonstrated

- Building interactive Power BI reports
- Creating tables, charts and map visualizations
- Using slicers and filters
- Working with data hierarchies
- Configuring drill-through functionality
- Comparing sales performance across years

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Navigate through the report pages.
4. Use the slicers and filters to explore the available data.
5. Select data points to explore the report's drill-through and hierarchy features.

## Conclusion

This project demonstrates how Power BI can be used to organize sales data into interactive visual reports, compare product performance and explore business information through filters, geographic views and detailed report navigation.
